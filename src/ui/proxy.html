Sistem proxy

Saat aktif, tiap akun memakai proxy miliknya sendiri di profilnya sendiri (tidak global, jadi bisa jalan paralel). Akun tanpa proxy memakai jaringan asli.

Identitas per akun

Atur siapa yang memakai User-Agent (sistem operasi) dan zona waktu sendiri di tab-nya. Akun ber-proxy mendapat profil acak dan zona waktu mengikuti negara IP proxy. Akun tanpa proxy sebaiknya memakai perangkat asli supaya cocok dengan IP aslinya. Bisa diubah manual di daftar akun di bawah.

Gateway proxy

Akun tersimpan

Pilih proxy untuk tiap akun. Mode Sticky = 1 akun selalu IP yang sama (paling aman). Mode Ganti IP = IP baru tiap kali akun dipakai.

Atur proxy sekaligus

Log aktivitas ganti akun

    Panduan singkat: cara {session} membuat IP sticky

    Gateway residensial bergilir memberi IP baru untuk tiap request. Supaya 1 akun selalu dapat IP yang sama, kita mengunci ID sesi di username. Ganti {session} di kolom Username dengan ID yang disimpan DHub per akun — DHub otomatis mengisinya.

    ProviderContoh username
    Bright Databrd-customer-hl_x-zone-y-zone-{session}
    Smartproxy / Decodocustomer-user-cc-id-session-{session}
    Oxylabscustomer-user-cc-id-sessid-{session}
    Generikuser-session-{session}

    Tanpa {session}, semua akun memakai IP yang sama persis — masih lebih aman daripada IP berganti tiap request, tapi sticky per akun adalah yang paling aman.

    Catatan: proxy dipasang ke profil tiap akun, bukan ke seluruh aplikasi. Akun dengan proxy berbeda bisa berjalan bersamaan tanpa IP tertukar. SOCKS5 dengan username/password tidak didukung Chromium; pakai HTTP/HTTPS atau whitelist IP.
